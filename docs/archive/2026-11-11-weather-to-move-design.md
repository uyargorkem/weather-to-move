# Weather to Move — hackathon demo design

> Original planning notes. See the [README](../../README.md) for the current setup and data pipeline.

Date: 2026-11-11. Status: approved (user), build order revised: UI with dummy data first, real Open-Meteo pipeline last.

## Goal
Demo on a saved Rightmove property page (`demo_page.html`, property 95181078, Magdalen Road SW18): a weather button next to the "Save this property" heart opens a right-hand panel with four two-year weather-insight metrics, linking to a fuller dashboard page.

## Architecture
- Single Vite project, React 19 + TypeScript, Meta Astryx (`@astryxdesign/core`, `@stylexjs/stylex`, `@astryxdesign/theme-neutral`).
- `src/inject.tsx`: loaded by one `<script type="module">` tag added to `demo_page.html`. Inserts a sibling button after `[data-test=saveHeart]`, mounts a React root in `#wtm-root` rendering the side panel. Astryx theme scoped to `#wtm-root`.
- `dashboard.html` → `src/dashboard.tsx`: full-page Astryx dashboard, `?property=<id>`.
- No backend. Data: `src/data/` with a `WeatherSource` interface; `openMeteoSource` (historical-forecast API first, ERA5 archive fallback, retry with backoff; hourly, `Europe/London`, 2 years ending today−7d; localStorage cache; bundled fixture fallback generated by `npm run prewarm`). `?source=dummy` forces placeholder numbers.
- `src/properties.ts`: id → {lat, lon, label}. Baseline: Greater London centroid (51.5074, −0.1278).

## Metrics (computed from hourly rows; pure functions, unit tested)
| Metric | Definition | Headline |
|---|---|---|
| Comfortable Outdoor Hours | 08–20h, apparent temp 14–26 °C, precip < 0.1 mm, wind < 25 km/h | hours/year |
| Usable Weekend Afternoons | Sat/Sun 12–18h; usable if ≥4 of 6 hours comfortable (temp ≥ 12 °C relaxed) | N of 104 per year |
| Rain During Commute | Mon–Fri 07–09 & 17–19; wet if any hour precip ≥ 0.2 mm | % commutes wet, count/yr |
| Wind-Driven Rain Exposure | precip ≥ 0.5 mm AND wind ≥ 20 km/h (gust ≥ 60 severe) | hours/yr + dominant direction |
Each metric carries a delta vs. baseline and a monthly breakdown.

## Panel
Right drawer ~420px (full width mobile): header, four stat cards (icon, name, headline, baseline delta badge, one-line takeaway, monthly mini-bars), footer button "See full breakdown →" to dashboard. Loading/error states.

## Dashboard
Header (property, range, baseline), hour×month comfort heatmap hero, one section per metric with a chart (monthly bars, weekend season grid, AM/PM commute bars, wind rose). Recharts, palette from Astryx tokens.
